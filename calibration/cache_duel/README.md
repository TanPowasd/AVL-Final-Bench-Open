# 强参考对手（hark 提供）

按 `organizer/CALIBRATION.md` 放在 `calibration/cache_duel/`，供作者在私有环境对官方对手校准。

## cache_duel：`hark_strong.py`

单文件、仅标准库，同时支持攻守。

- 防守：`pred`（按到达间隔 EMA 预测下次请求，驱逐预测最远的）和 `mark`（Marking 框架内用同一预测器）两臂，按窗口实测 OPT/M 选优；默认先用 `mark`，以防被自适应攻击针对。
- 攻击：在 C+1 个 key 上猜洞，用 8 个防守模型的混合后验找最可能缺失的 key；保底臂是在约 1.15C 个 key 上均匀随机。攻击方能看到命中反馈，所以能自己算出防守方缺失数和 OPT，按窗口实测在两臂间切换。

单局耗时远低于 1 s/步和 20 s/局的限制（整套 3 种子 × 3 配置 × 攻守约 7 s，含进程开销）。

已知上限：对随机驱逐防守，任何攻击都只能在 0.64 左右（均匀随机请求无法被在线算法预测）；对能自适应的攻击者，本防守在自对弈里约 0.36（同样被均匀随机攻击压住）。
