# 强参考对手（hark 提供）

按 `organizer/CALIBRATION.md` 放在 `calibration/cache_duel/`，供作者在私有环境对官方对手校准。

## cache_duel：`hark_strong.py`

单文件、仅标准库，同时支持攻守。

- 防守：`pred`（按到达间隔 EMA 预测下次请求，驱逐预测最远的）和 `mark`（Marking 框架内用同一预测器）两臂，按窗口实测 OPT/M 选优；默认先用 `mark`，以防被自适应攻击针对。
- 攻击：在 C+1 个 key 上猜洞，用 8 个防守模型的混合后验找最可能缺失的 key；保底臂是在约 1.15C 个 key 上均匀随机。攻击方能看到命中反馈，所以能自己算出防守方缺失数和 OPT，按窗口实测在两臂间切换。

### 64 种子循环赛（2026-11-05）

种子 1001–1064，`config` 的 3 组参数（C,K,N）=(8,64,3000)、(32,256,5000)、(64,4096,5000)，5 个程序两两攻守全打（含自对弈），共 4,800 局，用与 `engine/engine.py` 相同的 `belady_misses` 和 `role_seed` 的进程内模拟器。每个程序的分数 = 该种子下所有对局（攻守各半）得分的平均 ×100，置信区间按 64 个种子算。

| 程序 | 平均 | 95% CI |
|---|---|---|
| hark_strong | 72.85 | 72.79–72.92 |
| baselines/rand | 53.70 | 53.65–53.75 |
| baselines/lru | 47.51 | 47.47–47.54 |
| baselines/marking | 45.90 | 45.82–45.98 |
| baselines/fifo | 30.03 | 29.98–30.08 |

hark_strong 对各对手（每格 192 局）：

| 对手 | 防守 | 进攻 |
|---|---|---|
| fifo | 97.66 | 93.05 |
| lru | 99.50 | 93.04 |
| rand | 45.62 | 64.22 |
| marking | 69.98 | 65.46 |
| hark_strong（自对弈） | 33.56 | 66.44 |

单局耗时远低于 1 s/步和 20 s/局的限制（整套 3 种子 × 3 配置 × 攻守约 7 s，含进程开销）。

已知上限：对随机驱逐防守，任何攻击都只能在 0.64 左右（均匀随机请求无法被在线算法预测）；对能自适应的攻击者，本防守在自对弈里约 0.36（同样被均匀随机攻击压住）。
