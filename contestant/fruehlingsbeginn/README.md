# [Ynoi1998] Frühlingsbeginn

> 时间限制：1.40s（标准机 AMD Ryzen 9 9950X3D，评测时按本机 CPU 速度自动换算）| 内存限制：512MB | 语言标准：C++20（`g++ -std=gnu++20 -O2 -pipe`）

## 题目描述

给定 $n,m$，你需要维护一个 $[1,n)$ 的数轴上区间的初始为空的可重集合，支持三种操作共 $m$ 次：

1. 插入一个区间 $[l,r)$。
2. 删除第 $t$ 次操作插入的区间。
3. 给出一个区间 $[l,r)$，判断当前可重集合是否存在一个子集，使得子集中所有区间的并恰好是 $[l,r)$。

## 输入格式

第一行两个整数 $n,m$。

下面 $m$ 行，每行若干个整数描述一次操作，可能是 `1 l r`、`2 t` 或 `3 l r`。

## 输出格式

对于每个询问，输出一行一个大写字母 `Y` 或 `N`。`Y` 表示存在这样的子集，`N` 反之。

## 效率计分（时间与内存权重）

**这是一道测极限的题：只做对拿不到满分，必须做机制级优化。** 本题包含原始规模与超规模的结构化压力数据。除了正确性，评测还按你程序的**用时和峰值内存**扣分——请在保证正确的前提下，尽力压低时间和内存：选对复杂度之外，还要优化常数（快速 I/O、紧凑的内存布局、避免不必要的动态分配与拷贝、缓存友好的访问顺序、减少分支等）。

每个测试点的得分率再乘以效率系数 $E$：

$$f_t=\mathrm{clamp}\Big(\tfrac{\ln(t/T_0)}{\ln(T_L/T_0)},0,1\Big),\quad f_m=\mathrm{clamp}\Big(\tfrac{\ln(m/M_0)}{\ln(M_L/M_0)},0,1\Big),\quad E=(1-0.9f_t)(1-0.9f_m)$$

- $t$：整个进程的 CPU 时间（用户态 + 内核态），包含输入输出（标准毫秒，按标准机 AMD Ryzen 9 9950X3D 换算），$T_L=1400$ ms 为时限，$T_0=200$ ms 以内不扣分；
- $m$：峰值内存（MB），$M_L$ 为内存限制 512MB，$M_0=64$ MB 以内不扣分；
- 顶到时限只保留 10%，顶到内存限制只保留 10%，两者相乘，最低保留 1%（0.1×0.1）；超时/超内存仍按 0 分。
- 子任务得分 = 子任务分值 × 组内所有测试点 (得分率 × $E$) 的平均值，即每个点独立给分。评测报告同时给出只看正确性的分数（raw_score）与平均效率系数。
- $m$ 是操作系统报告的程序峰值内存，不含评测父进程；本地和正式评测都这样计算。
- 硬限制是虚拟地址空间不超过“题面内存限制 + 64MB”，栈上限相同。
- 正式评测对同一份编译产物连续完整测 3 遍，取总分最高的一遍。
- 提交必须是单线程程序，不得使用 `std::thread`、OpenMP、`fork` 等手段。评测不自动检测，发现使用的按该题 0 分处理。
