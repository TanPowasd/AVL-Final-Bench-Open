# 工业系统规则与完整初始目录

状态：**`rift_era_rules_r6`（已冻结，机器可读事实源为 [`data/industry.json`](data/industry.json)）**。历史提案推导见 [proposals/BA-world-init-extraction-and-macroeconomy.md](proposals/BA-world-init-extraction-and-macroeconomy.md) 与 [proposals/B-tech-modifiers-factory-ops-and-power-grid.md](proposals/B-tech-modifiers-factory-ops-and-power-grid.md)（若与本章或 `data/industry.json` 冲突，以 `data/industry.json` 与本章为准）。

## 地点、库存与生产

所有库存属于具体地点及所有者。工厂只能使用已经交付且有使用权的物资。货币不替代原料，购买不等于到货，研究完成不等于设备已经安装。

一个生产周期固定为 10 tick（2 个决策窗口），单局时长 2,880 周期（28,800 tick）。配方数量表示一条基准产线每周期的投入与产出，电力表示该周期需要的能量配额，劳动力表示当期占用的劳动单位（人口按 `0.65` 劳动参与率提供劳动单位，主要国家初始194平民对应126.1活跃劳动单位，6军职不重复参加生产）。

给定配方投入 a、产出 b、基准耗电 p、基准劳动 w，产线模式给出容量 c、单位耗电系数 f_p 和单位劳动系数 f_w。产线每 tick 按最高 `c / 10` 周期当量推进分步批量 `Δx_tick`，同时受本地期初可用库存 `available`、P3 阶段实分电量、可用劳动、设备可用率 $\alpha_{\text{avail}}$ 和出库仓容约束。消耗 `a * Δx_tick`，耗电 `(p * f_p) * Δx_tick`，占用劳动 `(w * f_w) * Δx_tick`；等级 2–3 的精密/芯片/传感器/航空轨道配方在未加装 `C01` 传感器质检时承受 `6%` 次品损耗（加装 `sensor × 1` 后恢复 `100%` 良率）。当步产出统一写入 `next_available` 缓冲区，在当步末提交后于下一 tick 起可供下游产线、运输或下一市场窗口使用，不得在同 tick 内跨产线串联级联。

所有数量与进度统一使用整数毫单位（按11任意精度规范）（`1 标准单位 = 1,000 mU`，对应 `quantity_precision = 0.001`）记账，未满最小精度的进度保留在产线内，不通过反复舍入创造物资。整机需要累积满 `1,000 mU`（1 个完整单位）后才转入 `next_available`；未完成部分留在产线，切换配方时未满 1 台的半成品进度报废。每座枢纽基础公共仓容为 `300` 单位（可扩建仓库模块每次 `+500`），满仓自动限产；超储粮食品每周期自然损耗 `1.5%`。

## 设施、模块化建设与维护欠账

设施外壳、配方和产线模式分别检查。建造 `S2/S3/S4` 外壳须先掌握 `L01 土木工程`（允许进口装机组件）。掌握 `L08 模块化建造` 后，可用 `structure_module` 按 `1 : (steel×1 + cement×1.5)` 替代至多 `50%` 现场结构钢材与水泥，最高缩短 **35% 现场工期**。

表中的 installed 是产线装机一次性消耗，不是每个周期重新消耗。设施外壳建设材料与装机材料分别计费，不能将同一份设备同时安装在两条线上。S4 是高密度双线设施，不是研究四阶科技的强制前置；它节约城市建设槽位，但造价和依赖更高。

产线模式只适用于数据中列出的制造厂类，不给农场、电站或实验室直接套用制造倍率。模式变化需要装机物资和停机，已有设备不能在换线时复制。更换配方但不换模式按该模式的转产周期停机（解锁 `R04 计量标准` 后专用线转产由 `8` 周期缩至 `6` 周期）；跨厂类转产不允许通过一次配方切换完成。

每 `20` 周期强制结算一次设施维护物资。库存不足导致的欠缴比例累加为欠账期数 $D_{\text{maint}}$，设备可用率按 $\alpha_{\text{avail}} = \max(0.20,\, 1 - 0.30\,D_{\text{maint}})$ 线性下降；当 $D_{\text{maint}} \ge 2.0$ 时每周期触发 $8\% \times D_{\text{maint}}$ 概率的故障停产（停机 `4` 周期）。须补齐历史欠账的 `1.20×` 维护件并检修 `2` 周期方可清零恢复。

1. **六态机组状态机（`OFF / STARTING / ON / TRIPPED / MAINTENANCE / SCRAM`，`AR-015` 完整闭式转移）**：
   - **`OFF`（冷停机）**：出力 $x_t = 0$，不消耗燃料与冷却水。收到开机指令或电网自动开机信号（`online = True`）时转入 `STARTING`（启动计时器设为 $\tau_{\text{start}}$；若 $\tau_{\text{start}} = 0$ 且具备燃料/水源则同步直接转入 `ON`）。
   - **`STARTING`（冷启动预热）**：在连续 $\tau_{\text{start}}$ 个 `tick` 内对外净出力为 `0`；
     - **聚变（`P086`）外部点火功率**：`P086` 在 `100 tick`（`10` 周期）冷启动期间，作为第 `B0` 级刚性负荷每 `tick` 从所在电网消耗 **`4.0` 电（即每周期 `40.0` 电，累计 `400.0` 电）**；若冷启动期间任一 `tick` 的 `B0` 供电满足率 $< 100\%$，点火中断且启动计时器归零。
     - **并网点亮直接进入有效最低稳燃水平 $x_{\min}^{\text{eff}}$（彻底消除 `0 → 5% < 70%` 死锁）**：当冷启动计时满 $\tau_{\text{start}}$ 的首个并网 `tick`（且当步 `P1` 预留的燃料、人力与冷却水比例 $\bar{x}_u(t) = \min(\alpha_{\text{avail}}(u,t),\, r_{\text{fuel}}(u,t)) \ge 0.30\,x_{\min}$），机组**直接以有效最低稳燃比例 $x_t = x_{\min}^{\text{eff}}(u,t) = x_{\min} \cdot \bar{x}_u(t)$ 并网转入 `ON` 状态**（满可用率 $\bar{x}_u = 1.0$ 下：`P070` 燃煤并网初值 $x_t = 0.40$，`P073/P083` 核电并网初值 $x_t = 0.70$，`P086` 聚变并网初值 $x_t = 0.50$）！开局 $T = 0$ 时各国初始 `P070` 燃煤电站均处于已并网 `ON` 状态（初值 $x_0 = 0.75 \in [0.40, 1.00]$）。
   - **`ON`（在网运行）有界可行区间、低可用率/断燃料脱网与排汽弃电规则（消除 `floor > ceil` 无解区间，`AR-015`）**：
     - **物理上限与低可用率/断燃料自动脱网（`ON → OFF`）**：在每 `tick` `P3a` 预检阶段，核定机组当前物理可用上限 $\bar{x}_u(t) = \min\!\big(\alpha_{\text{avail}}(u, t),\; r_{\text{fuel}}(u, t)\big) \in [0, 1]$（其中 $r_{\text{fuel}}(u, t) \in [0, 1]$ 为 `P1` 燃料预留满足率）。若燃料耗尽（$r_{\text{fuel}}(u,t) = 0$）或因维护欠账/战损导致 $\bar{x}_u(t) < 0.30 \cdot x_{\min}(u)$，机组无法维持炉膛稳燃/临界状态，**在 `P3a` 立即自动熄火转入 `OFF` 状态**（$x_t = 0$，不进入 `P3b` 调度）。
     - **保证恒非空的 `ON` 可调度出力区间 $[\,x_{\text{floor}}(t),\; x_{\text{ceil}}(t)\,]$**：当 $\bar{x}_u(t) \ge 0.30 \cdot x_{\min}(u)$ 时，机组有效最低稳燃线按可用上限等比折算为 $x_{\min}^{\text{eff}}(u, t) = x_{\min}(u) \cdot \bar{x}_u(t) \le \bar{x}_u(t)$，上下界闭式定义为：
       $$x_{\text{ceil}}(t) = \min\!\big(\bar{x}_u(t),\; x_{t-1} + r\big), \quad x_{\text{floor}}(t) = \min\!\Big(x_{\text{ceil}}(t),\; \max\!\big(x_{\min}^{\text{eff}}(u, t),\; x_{t-1} - r\big)\Big)$$
       **反例验证（`AR-015`）**：设核电机组（$x_{\min} = 0.70, r = 0.05$）上一拍出力 $x_{t-1} = 0.70$，本拍因维护欠账可用率骤降至 $\alpha_{\text{avail}} = 0.40$（$\ge 0.30 \times 0.70 = 0.21$），则 $x_{\min}^{\text{eff}} = 0.70 \times 0.40 = 0.28$，$x_{\text{ceil}}(t) = \min(0.40, 0.75) = 0.40$，$x_{\text{floor}}(t) = \min(0.40, \max(0.28, 0.65)) = \mathbf{0.40}$，可行区间为 $[0.40, 0.40]$，恒满足 $x_{\text{floor}}(t) \le x_{\text{ceil}}(t)$，绝不发生 `floor > ceil` 无解死锁！
     - 燃料与冷却水严格按实际物理发电比例 $x_t \in [x_{\text{floor}}(t), x_{\text{ceil}}(t)]$ 消耗（满发消耗 $\times x_t$）。
     - **低负荷保底稳燃与排汽弃电（`Steam Dump / Curtailment`）**：若某 `tick` 子电网实际负荷需求低于在运机组的下限 $x_{\text{floor}}(t)$，机组**绝不跳闸熄火**，而是维持在 $x_t = x_{\text{floor}}(t)$ 稳定燃烧（按 $x_{\text{floor}}(t)$ 消耗燃料），向电网输送所需电量并将多余热能通过旁路安全排空（除非玩家显式下达关机指令使其转入 `OFF`）。
   - **核能冷却泵电力/水源定量、`P3a → P3b` 无环时序、热应力消退与 `SCRAM` 保护（`P073, P083`）**：
     - **冷却泵 `B0` 定量负荷与水源锁定**：每座处于 `ON` 或 `STARTING` 状态的核电机组（`P073` 或 `P083`），其主冷却泵固定占用 **`0.50` 电/周期（`0.05` 电/tick = `50 mU/tick`）** 的本地 `B0` 第 1 优先级负荷；其冷却水需求（`P073` 每 `tick` `0.20` 水、`P083` 每 `tick` `0.05` 水）在 `P1` 阶段纳入枢纽刚性保命锁定量 `locked_subsistence[hub, "water"]` 优先锁定。
     - **`P3a` 调度前预检与 `P3b` 单遍出清（消除“供电 $\leftrightarrow$ SCRAM”同拍循环）**：
       - 在每tick进入P3b前，P3a检查本拍冷却水锁定率 $r_w(t)$ 与上一拍实际结算的泵供电满足率 $r_{\text{B0}}^{\text{pump}}(t-1)$。前拍泵未运行时不追认一次欠供；前拍泵运行且满足率小于1时，本拍立即SCRAM。该历史满足率只读，P3a不扣SOC、不回填历史；储能只有在实际供泵的那一拍经P3成交并扣SOC后，才计入该拍泵供电。
       - **正常满水与热应力消退（$r_w(t) = 1.00 \land r_{\text{B0}}^{\text{pump}}(t-1) = 1.00$）**：反应堆正常运行，且已累积的堆芯热应力按每 `tick` **`-0.01`（即每周期 `-0.10`，连续满水运行 `20` 周期 = `200 tick` 消退 `-2.00`）** 线性恢复：
         $$S_{\text{therm}}(t) = \max\!\big(0.0,\; S_{\text{therm}}(t-1) - 0.01\big)$$
       - **紧急降载窗口（$0.50 \le r_w(t) < 1.00 \land r_{\text{B0}}^{\text{pump}}(t-1) = 1.00$）**：在 `P3a` 将机组当拍出力上限强制压降至 $\bar{x}_u(t) = \min(\alpha_{\text{avail}},\, r_w(t))$（允许跟随 $x_{\min}^{\text{eff}} = 0.70\,\bar{x}_u(t)$ 降载维持在网），同时累积热应力 $S_{\text{therm}}(t) = S_{\text{therm}}(t-1) + (1.0 - r_w(t))$；
       - **紧急停堆（`SCRAM`）触发与检修重置**：一旦在 `P3a` 检出 ① $r_{\text{B0}}^{\text{pump}}(t-1) < 1.00$（上一拍冷却泵实际欠供；不接受本拍储能追补）、② $r_w(t) < 0.50$（严重断水）或 ③ $S_{\text{therm}}(t) \ge 2.00$，反应堆在 `P3a` 立即转入 `SCRAM` 状态（当拍 $x_t = 0$，不进入 `P3b` 发电栈；强制离线 `10` 周期 = `100 tick`，期满并消耗 `precision_parts × 2 + pure_chemicals × 1` 检修完成后，**热应力重置为 $S_{\text{therm}} = 0.0$** 并转入 `OFF` 状态）。
   - **`TRIPPED`（强迫停运/跳闸）与 `MAINTENANCE`（计划检修）到期返回状态**：
     - 强迫停运每周期初按种子流 `(match_seed, "outage", cycle, plant_id)` 抽取，停运率乘以 $(1 + D_{\text{maint}})$，触发后转入 `TRIPPED` 停机 $3 + \lfloor 6u \rfloor$ 周期。计划检修转入 `MAINTENANCE`，玩家可提前或推迟至多 `20` 周期（推迟超 `20` 周期后强迫停运率 `×3`）。
     - **到期状态转移**：当非黑网 `TRIPPED` 停机倒计时或 `MAINTENANCE` 检修倒计时归零时，若该机组的运行开关为 `online = True`，自动转入 **`STARTING`** 状态（重新执行 $\tau_{\text{start}}$ 预热后以 $x_{\min}^{\text{eff}}$ 并网；$\tau_{\text{start}} = 0$ 的机组直接转入 `ON`）；若玩家已将其设为 `online = False`，则转入 **`OFF`** 状态。
2. **级联停电（黑网）与 `BLACKOUT_RECOVERY` 黑启动状态机（消除恢复期二次跳闸死循环）**：
   - 每个同步子电网 $G$ 维护电网运行模式 `grid_mode ∈ {"NORMAL", "BLACKOUT_RECOVERY"}`：
   - **黑网触发（`NORMAL → BLACKOUT_RECOVERY`）**：在 `NORMAL` 模式下，若某 `tick` 子电网 $G$ 的总可调度供电能力 $< 0.70 \times (D_{\text{B0}} + D_{\text{B1}})$，触发全网低频解列：该子电网内所有当前处于 **`ON`** 状态的发电机组同步跳闸转入 `TRIPPED`（冷却 `1 tick` 后于下一 `tick` 自动转入 `STARTING`），子电网模式切换为 **`BLACKOUT_RECOVERY`**；
   - **黑启动爬坡期豁免（`BLACKOUT_RECOVERY → NORMAL`）**：在 `BLACKOUT_RECOVERY` 模式下，**暂停执行 `< 70% (B0 + B1)` 级联跳闸判定**（防止黑启动机组刚点亮又被瞬间跳闸！）。零启动时长电源（P074氢能、风光，以及已预选discharge且有SOC的E04储能）于第1tick参与供电保B0；auto为idle/charge的储能不会因黑网自动改向，随后快启水电/燃气（`1 tick` 后并网）、燃油（`2 tick` 后并网）、燃煤（`5 tick` 后以 `40%` 稳燃并网并按 `10%/tick` 爬坡）依次恢复出力；当子电网总可调度供电能力重新达到 **`>= 0.80 × (D_B0 + D_B1)`**（含 `10%` 迟滞回差）时，子电网恢复为 `NORMAL` 模式。

### 2. 天气（种子化、确定性）

每个 `L2` 陆地分区 $r$ 每 `tick` 更新（`P2`），全部取自流 `(match_seed, "weather", tick, r)`，$\varepsilon \sim \mathcal{N}(0,1)$：

- 风况：$W_r(t) = \text{clip}\big(\bar W_r + 0.8\,(W_r(t-1) - \bar W_r) + 0.12\,\varepsilon_W,\ 0,\ 1\big)$；$\bar W_r \in [0.20, 0.50]$ 由地图生成器按地形给出。
- 云量：$K_r(t) = \text{clip}\big(\bar K_r + 0.7\,(K_r(t-1) - \bar K_r) + 0.15\,\varepsilon_K,\ 0,\ 1\big)$。
- 日照：一周期视为一昼夜，$\text{day}(k) = \max\big(0, \sin(\pi (k - 1)/6)\big)$，$k = t \bmod 10$（`tick 1..7` 有日照，峰值在 `tick 4`；`tick 0, 8, 9` 无日照），$S_r(t) = \text{day}(k)\cdot (1 - 0.7 K_r(t))\cdot \text{lat}_r$，纬度系数 $\text{lat}_r \in [0.6, 1.0]$。
- 河流来水：$Q_r(t) = \text{clip}(\text{实际出流}/\max(\text{基准出流},0.001),0,1.2)$（详见 [02 流域水文闭式公式](02_economy_logistics_governance.md)）。
- `N08` 提供提前 `3` 周期的外生气象场确定性预报（仅下发未来 `30 tick` 的外生气象增量，不泄露未勘探区秘密基数 $Q_r^{\text{base}}$）。

### 3. 电网区域、多跳乘法线损与储能

1. **同步电网与多跳乘法线损**：
   - **电网区域**：由已建成且在运的高压走廊（`E02/E09/E12`）连通的枢纽集合构成同步电网 $G$。每 `tick` `P3` 开始时重新计算连通分量。
   - **单段与多跳路径线损（`Multiplicative Path Loss`）**：每条走廊 $\ell$ 容量 $\bar F_\ell$（单回 `60`、双回 `120`、超导 `240` 电/周期，每 `tick` 为 `1/10`），单段线损率 $\lambda_\ell = \min(35\%,\ 1.5\% \cdot D_\ell/10)$（`E07` 后 `0.9%`，`E09` 超导 `0.2%`，`E12` 跨洲封顶 `8%`）。当电力沿多跳路径 $\mathcal{P} = (\ell_1, \dots, \ell_m)$ 从送端 $u$ 输送至受端 $v$ 时，沿途存活率按**连乘**计算：
     $$\eta(\mathcal{P}) = \prod_{\ell \in \mathcal{P}} (1 - \lambda_\ell), \quad f_{\text{recv}}(v) = f_{\text{sent}}(u) \cdot \eta(\mathcal{P})$$
2. **三类储能参数表与无环套利基准**：

| 储能 | 前置 | 设施与装机 | 能量容量 | 充/放功率（电/周期） | 往返效率 $\eta_{\text{rt}}$ | 衰减与维护 |
|---|---|---|---:|---:|---:|---|
| 电化学储能站 | `E04` | `S2` 槽位 + `battery × 8` | 80 | 10 / 10 | 85% | 每等效满循环健康度 `-0.8%`，`< 80%` 补 `battery × 2` |
| 抽水蓄能 | `E02 + L01` | `S2` 槽位（山地+河流区）；建设 `steel 30 + cement 60 + basic_parts 6`，工期 `30` 周期 | 400 | 40 / 40 | 75% | 无循环衰减；来水 $Q_r < 1$ 时可用蓄能上限按 $Q_r$ 折减 |
| 氢储能 | `E06` | `P024` 制氢 + 储罐库存 + `P074` 发电 | 按 `hydrogen` 库存 | 由产线数决定 | 约 25% | 无 |

   - 充电效率与放电效率各取 $\sqrt{\eta_{\text{rt}}}$，荷电状态 `SOC` 以 `mU` 记账。
   - **`auto`模式先选方向，再单边报价**：每周期首tick的P1读取截至上一周期末的本地Hub实付均价 $p_{h,c-1}$ 与近10周期同一Hub价格中位数 $m_h$，均以RU/电计。历史不足10期时取已有周期；完全无历史则idle。若 $p_{h,c-1}<0.85m_h$，本周期只申报充电买价 $b_{\text{chg}}=0.85m_h$；若 $p_{h,c-1}>1.15m_h$，只申报放电卖价 $o_{\text{dis}}=\max(\text{avg_charge_cost}/\eta_{\text{rt}},1.15m_h)$；其余含等号为idle、不挂单。方向冻结至周期末；已有单边报价仍受本tick实际SOC、功率、预算和网络容量限制。不得同时挂充/放两边，也不因本周期故障或现价改变方向。

### 4. 逐路径配电与按成交报价结算（Round 4，AR-016/017/045）

取消Round3沿“实际潮流DAG”递推节点价格的规则；多笔简单路径的并集可能有环，价格下限连乘会无解。当前规则采取**按实际成交切片及损耗收费**，不称LMP，不产生未经资金支持的阻塞租。代价是价格不再表达全网边际机会成本，后续需比较策略/效率。

1. P1按期初燃料、冷却、可用劳动计算本tick机组上下限；燃料/冷却预约守恒，调度结束只消耗实际物理发电部分，最低稳燃多余量作弃热不收费。报价MC=(燃料参考成本/额定输出)+OM，OM火核氢.2、风光水.05；最低稳燃切片为0报价，但真实燃料仍已购且会消耗。所有报价转期初汇率RU。无任何国库自动保本补贴，经营者可选择关机。
2. 买方P1预留可支付RU预算（需要换汇须已成交），用户电价cap补贴也须真实预留；无钱的需求先缩至可负担量，不能本拍免费用电、下拍才停。负荷预算约束含用户+已锁补贴；buy_limit为用户声明全额送达保留价。B0固定rank0；各国自定B1..B4置换映射rank1..4，跨国同rank一起处理；B5固定rank5。默认B0–B4限价50本币，B5申报0..50。
3. 按rank升序：先本地自供，按机组报价/H排序，受买价和预算约束；再处理可达的未满足负荷。当前满足率最小者优先，并列按H(seed,tick,rank,load_id)。源-汇在残余网络中选择送达成本最小**简单路径**，平局先边数再路径H；成本=源报价/路径存活率+各边每送端单位.01RU通行费折至受端。枚举语义唯一，实现可用非负广义最短路；同方向共享边容量，双向占同一总容量，不能两方向各得满额。
4. 最小分配量1mU受端电。对选定负荷/路径，按该（源，负荷，路径）的累计受端量从受端反向逐边ceil到mU得累计送端量，本次源/边用量为其与上次累计值之差，必须满足源/边容量与锁款；不可行则排除该路径再选，穷尽则本rank冻结该负荷。连续批量可以一次推进至下个满足率交点/容量/预算/需求边界，结果必须等价逐mU序列。排除不可达负荷后继续别的负荷；不把A10电、A/B需5、边cap1错误缩成各3，实际本地A5、B1。所有配额守恒，余量可给后rank，故不宣称全局max-min最优。
5. B5按保留买价降序先分档，同价使用上述满足率与路径规则。每笔成交的实际送达价格必须≤该B5限价，任意其他负荷开启不会追溯抬高已经成交电价。高优先级未满足但不可达的负荷不阻止孤立子区B5利用剩余电；同一可达源的余量必已先供高优先级。
6. 结算按路径receipt：用户+补贴真实借记=源实际注入量×该切片报价+沿路实际送端量×.01RU。发电方和线路方依这同一receipt分账；所有舍入按11，线路收入为非负通行费，不是节点价格差。单源100送90、源价1、无收费示例：受端90电共付100，单价100/90，源收100。A低价1与高价10分别供两类负荷，已成交低价电不改收10。
7. 本地统计电价为该Hub实际使用电量加权送达价；零用电沿用前价（初值2本币），另报欠供率。用户cap仅分摊付款来源，不降低发电应收；锁定补贴不足时在准入阶段缩量。CPI读取该统计价，不能用统计价重新结算。

auto储能方向与单边报价唯一按§3“先选方向，再单边报价”执行；例如历史中位10RU、上期Hub价10RU，本周期即使燃油边际价升到15RU也保持idle。手动charge/discharge/idle同拍互斥，不能给自己充放电或重复扣核泵SOC。
