# 设计理念

## 核心目标

让模型在信息不完整、各系统相互依赖、行动有延迟与不可逆成本的世界里，形成并持续修正国家战略。局部战术优化应该有价值，但无法替代全局资源、时间和关系管理。

现有「前沿实验室」已包含隐藏缩放律、带噪观测、长周期投资、产业调度和市场对抗。本题期望进一步增加空间物流、多个自主对手、分散控制权、国内约束和反馈链的共同决策难度。不能用两题的百分制分数大小直接证明谁更难。

## 核心世界观：控制权分层

同一块土地可以拥有不同的主权方、军事控制方、设施所有者、交通使用者和地方支持对象。一条跨境铁路可能位于甲国，由乙国经营，为丙国运输，并受到丁国军力保护。冲突可以改变其中某一层，而不自动取得所有层的权益。

这使战争、投资、条约、产业依赖和地方治理都能影响同一项资产。地图不是唯一的实力账本。

## 必须产生的策略矛盾

| 矛盾 | 希望模型考虑的内容 |
|---|---|
| 当前收益与未来条件 | 使用某种资源是否破坏了之后更重要的机会 |
| 产业集中与韧性 | 高效率是否依赖一个港口、一座电站或一个供应商 |
| 技术性能与可维护性 | 高端装备是否有足够备件、人员和能源来持续发挥作用 |
| 进攻与维持 | 占领后的交通、治理、维修与驻防成本 |
| 自主与合作 | 自建全链条的代价，与依赖别人带来的风险 |
| 信息与行动 | 情报的时效、可信度、获取成本及可能造成的暴露 |
| 中央计划与地方响应 | 命令是否有通信、授权、支持和物资保证 |
| 国家目标与共同环境 | 自身决策如何改变邻国以及共享系统的行为 |

## 复杂性的来源

增加机制必须能说明它连接了哪些已有决策。优先增加可解释的反馈关系，而不是不相关的资源条、每日领奖、随机惩罚或同功能科技的重复升级。

世界可以复杂，但动作应支持持续计划、批量任务与优先级。复杂度不应主要来自每秒重复点击、阅读巨量无关日志、猜接口或依赖更快的实际电脑。

物资守恒、库存位置、时间延迟和产权记录应明确。允许贸易获利和战略欺骗，但不能利用重复结算、无限回收、空合同计分或自买自卖制造国力。

## 技术路线的意义

“可选择”包括研究顺序、国产或进口、成熟或高端工艺、人工或自动化、集中或分散供能，以及装备和产线架构。知识原则上可以兼得，但同一批资源、人员、建设用地和时间不能同时用于所有路线。

同一产线、设施或装备的架构在同一时刻只能选择一个，改造要消耗资源和时间。旧路线应保留用途，不让所有选择都退化成尽快解锁同一个顶级方案。

## 暂不追求的内容

当前不需要画面、美术、自然语言谈判裁判或现实军事/工业复刻。经济与工艺数字是抽象游戏规则。人口与部队采用群体建模，避免为了视觉上的世界规模逐个模拟居民。

新颖性、难度优势、战略多样性和计算成本都是未来需要验证的性质；这份设计包不提供尚未发生的验证结果。

2. **第二优先级（Tier 2：正式规范章节）**：第 `00–07` 章与第 `10–11` 章（`00_design_principles.md` 至 `07_scoring_and_resources.md`、`10_system_coupling.md`、`11_execution_contract.md`）。
