# 0002：超大陆双层世界拓扑、长周期三级时钟与同 Tick 无偏守恒流水线

状态：用户已明确“采用双层空间、地图做大、局长拉长、每窗口集合竞价出清”，现合入设计草案 `v0.2`（具体算力与内存吞吐仍待原型实测验证）。

## 背景与旧语义（`v0.1`）

- 空间层候选规模为 `256×256` 地块、8 国与约 24 城邦，未拆分底层几何栅格与高层区域网络拓扑，战略纵深与跨洲远洋空间有限。
- 时间层仅暂定 `10 tick = 1 生产周期`，未确定单局总长度、策略决策窗口间隔与市场出清频率。
- 同 tick 结算尚未闭合“到货可用时点、停电与开火先后、新产出可售时点、消除座位遍历偏置”四大边界。

## 新语义（`v0.2`）

1. **做大后的多大陆双层耦合空间模型**：
   - **L1 地理栅格层（扩大至 `512 × 512` 地块，共 `262,144` 格，面积为 `v0.1` 的 4 倍）**：呈现多块裂解大陆、远洋航道、群岛链、内海海峡、山脉屏障与大河流域；仅在 `init` 紧凑下发并在地形工程或重大环境变化时发送差分。专门服务于真实跨洲距离、输电距离损耗（`E02`）、临水港口（`L04`）、地峡运河与穿山隧道几何选址（`L06`）、流域上下游水文（`A01`）以及雷达与近地轨道覆盖遮挡（`G05`、`N06`、`C08`）。
   - **L2 战略分区与枢纽网络层**：全图划分为候选 **`340..420` 个陆地分区 + `80..120` 个海域/洋区/海峡分区（合计 `420..540` 个表层分区）+ 同构空域层 + `16..24` 个近地轨道槽位**；包含 **8 个主要国家**（每国具备纵深腹地与前线缓冲带）、**约 `36..48` 个中立城邦与自治领**、约 **`220..280` 座城市与战略枢纽（`Hub`）** 以及 **`1,100..1,500` 条分模态走廊边**。库存、设施、人口与走廊机动驻留于 L2，保持单步图推进复杂度为 $O(|V| + |E|)$。
2. **拉长后的三级锁定比例时钟 + `int64` 毫单位账本**：
   - 全局库存、资金、研究点、电量与行军进度统一采用 `int64` 毫单位（`1 标准单位 = 1,000 mU`），兼容 `quantity_precision = 0.001`。
   - **单局候选总长拉长至 `9,600 Tick` = `1,920` 个决策窗口（`1 Window = 5 Tick`）= `960` 个工业周期（`1 Cycle = 10 Tick`）**，划分为四个宏大战略纪元（每纪元 `240` 周期 = `2,400 Tick`），包含 `48` 次定期设施维护结算（每 `20` 周期一次）。拉长的时钟与做大的多大陆版图相匹配，确保跨洋远征、大陆干线铁路、运河贯通、`S4` 工业基地回本、初始矿脉枯竭与闭环回收/新能源转型能够完整展开。
   - **已被取代（2026-11-03，v1.2）**：单局长度 `9,600 Tick` / `960` 周期 / 每纪元 `240` 周期 / `48` 次维护结算由 [0010](0010_longer_game_population_and_package_submission.md) 第 1 条取代为 `28,800 Tick` = `5,760` 窗口 = `2,880` 周期（每纪元 `720` 周期，维护结算 `144` 次）。窗口、周期长度与 `P1–P8` 流水线不变。
3. **每窗口集合竞价与 `P1–P8` 双缓冲无偏结算**：
   - 市场采用**每决策窗口末（每 `5 tick`，于 `t % 5 == 4`）统一出清价双边集合竞价**，成交仅在交货枢纽原地转入买方 `next_available`。
   - 严格执行 `P1 命令接入与预算锁 → P2 走廊同档等比配给与到货入 available → P3 电站扣料与分带供电 → P4 统一快照移动截击与同时射击 → P5 窗口末集合竞价过户 → P6 产线/科研/施工分步推进（产出入 next_available） → P7 周期民生财政与缓冲提交 → P8 权限过滤观测生成`。
