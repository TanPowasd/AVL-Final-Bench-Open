# 0004：开局自举配平、12 种资源采掘衰竭、七类物理走廊与三部门宏观经济闭环

状态：已采纳并合入设计规范（世界生成种子拒绝率、尾矿衰竭拐点与税率弹性仍待原型实现后实测调优）。

## 背景与旧语义

- `v0.1`–`v0.2` 规定了工业配方目录与 `P1–P8` 结算顺序，但未给出主要国家与中立城邦的 `T=0` 定量初始资产、12 种自然资源的采掘设施与枯竭/再生方程、多模态走廊与地形工程的造价运力，以及人口消费篮子、货币流转与主权破产规则（对应 `Q04`、`Q05`、`Q08`）。

## 新语义

1. **8 大国与 `36..48` 城邦开局配平及自举校验闸门**：
   - 每主要国家初始拥有 `18..24` 个主权分区（含 `5` 座核心枢纽）、`200.0` 人口单位（提供 `130.0` 活跃劳动单位）、`18` 座已装机 `S1` 基础生产/发电/农业/科研设施、`9` 座 `G1` 采掘/取水场、`15` 周期安全缓冲库存、`3` 辆存量运输车、`2` 支驻防编队及 `100,000` 主权货币；全部初始电、水、煤、粮、钢、机件维护与用工在 `T=0` 满足严格正余量。
   - 本土保证基础生存六源，5 种战略升级矿（油、气、铝土、稀有矿、铀矿）按大陆非对称分布（单国本土至多富集 2 种），其余分布于他国及 `36..48` 个中立城邦。世界生成器强制执行 `T=0` 自举可达性校验闸门。
2. **12 种自然资源采掘、尾矿衰减与流域水文**：
   - 定义 `G1`（`BASE`）与 `G2`（`L01` 等解锁）两档采掘/采集场造价、工期、用工用电与基准产出。
   - 10 种 `finite_deposit` 矿藏在剩余储量比 $\rho < 0.30$ 时按 $\eta_{\text{dep}}(\rho) = 0.25 + 0.75(\rho / 0.30)$ 进入尾矿衰减；`water` 受降水与上游 `L06` 截流方程约束（`A01` 水库平滑波动），`biomass` 服从逻辑斯蒂再生与过伐水土流失反馈。
3. **七类独立走廊、无车人力基荷与 `L08` 模块化建造**：
   - 定量定义 `G1/G2` 公路（含每周期 `8` 单位无车人力基荷，防止 `L02` 前死锁）、干线铁路（`L03 + locomotive`）、内河航道、远洋海运（`L04 + N04 + freighter`）、航空走廊（`L05 + transport_aircraft`）、高压电网（`E02` 距离线损）及 `L06` 地峡运河/穿山隧道参数。
   - `L08` 解锁的 `structure_module` 可按 `1 : (steel×1 + cement×1.5)` 替代至多 `50%` 现场结构建材，最高缩短 **35% 现场建设工期**。
4. **民生消费篮子、守恒货币循环与主权破产重整**：
   - 定量锁定每 `20.0` 人口每周期对 `food`、`water`、`consumer_goods`、`electricity`、`medicine` 与 `medical_supplies` 的分级需求及断粮惩罚。
   - 货币在国库、地区居民储蓄池、城邦金库与托管账户间严格守恒循环（严禁凭空印钞）；欠薪直接触发对应比例旷工降产，连续 `3` 周期无力偿付触发自动主权破产重整（扣减信用、过户抵押物、折价拍卖非口粮国储清偿欠款）。
