## 要解决的问题

1. **18 项非配方科技尚缺精确数值语义与叠加边界（`Q09`）**：`technology.json` 共 64 项科技，其中 46 项直接解锁 `industry.json` 中的配方或产线模式，其余 18 项（`A01, A07, C08, E02, E07, E08, G01, G02, G07, L01, L06, L07, N08, R01, R02, R05, R06, R08`）跨及电网、地形、物流、质检、指挥、星座与研发制度，必须给出精确装机条件、强度系数与防无限叠加规则。
2. **研发项目中断、迁移、泄密与人员培训缺乏定量公式（`Q10`）**：当研究所遭遇轰炸、断电或主动迁址，或进行跨国技术许可时，进度折损与人力转化速度尚未定义。
3. **工厂运行边界（仓储上限、质检良率、维护欠账停机）未闭合（`Q11`）**：若仓库容量无限或欠缴维护仍可照常满产，`L07 自动物流`、`C01 测量仪器` 与 `S1–S4` 维护表将沦为摆设。
4. **电网损耗、电化学储能寿命与核电冷却安全未定量（`Q17`）**：风光波动、电池充放折旧与 `P073` 核电断水后果需要精确物理状态机。

- **零免费全局光环**：解锁任何科技仅授予“建造/安装/配置权限”，旧设施或旧编队必须消耗对应实物组件并经历停机改造后方可获得加成。
- **乘法有界叠加**：不同子系统的修正系数按乘法计算，且任何单项资源消耗折扣下限锁定为基准值的 `40%`，杜绝减免至零成本。

### 2. 研发项目并行、中断、迁移与保密制度（`Q10`）

1. **多线并行递减律**：若将 $N$ 条实验室产线投入同一科技项目，有效研究点汇总倍率为 $N^{\alpha}$（默认 $\alpha = 0.75$，解锁 `R05` 后 $\alpha = 0.92$），防止早期堆叠十几个廉价 `S1` 实验室瞬秒高阶理论。
2. **三档研发制度选项**（每个在研项目独立设定，切换需 `2` 周期整顿）：
   - **公开学术模式（`open`）**：研究点产出速度 **`+10%`**，但验证完成后与本国有贸易或人员往来的国家研究同项目时自动享受 `15%` 知识溢出折减；
   - **标准工业模式（`standard`）**：`1.0×` 基准速度，无自动外溢，但外国高阶情报行动可探知在研主干方向；
   - **绝密国防模式（`classified`）**：研究点产出速度 **`-10%`** 且额外消耗 `10%` 行政经费，但对外完全隐藏目标科技 ID 并阻断情报渗透。
3. **人员技能硬约束**：`S1` 基础实验室可由熟练技工与少量工程师混编运行；`S2` 工程实验室（`P076`）与 `S3` 计算实验室（`P077/P079`）要求至少 **`60%` 劳动单位来自工程师/科研人员池**，缺口部分无法用普通劳工顶替（必须通过 `R02` 提前育才）。

### 3. 工厂质检良率、仓储物理上限与维护欠账状态机（`Q11`）

1. **计量质检与制造良率（赋能 `C01 测量仪器`）**：
   - 生产等级 `1` 的基础大宗配方默认良率为 `100%`；
   - 生产等级 `2` 与 `3` 的精密机械、芯片、传感器、制导及航空轨道组件配方，在未加装检测仪器的产线上默认存在 **`6%` 次品损耗**（实际产出乘以 `0.94`）；解锁 `C01` 并在每条 `S2+` 产线一次性加装 `sensor × 1` 后，良率恢复至 **`100%`**（若同时解锁 `R04 计量标准`，专用线 `specialized` 转产停机由 `8` 周期缩短至 `6` 周期）。
2. **分枢纽分类仓储上限与损耗**：
   - 每座核心枢纽自带基础公共仓容 **`300` 标准单位**；可建造仓储扩建模块（消耗 `steel×8, cement×10`，每座增加 `+500` 单位仓容）。
   - 出库区满仓时对应产线在 `P6` 自动限产停机（绝不凭空溢出蒸发，也不允许无限零成本囤货）。
   - **易腐与危化品约束**：超出冷链/粮仓定额的 `grain` 与 `food` 每周期自然霉变损耗 `1.5%`；高危品（`fuel`、`ammunition`、`precision_ammunition`、`chemicals`、`hydrogen`）若单枢纽超储且遭遇轰炸，会触发殉爆附加伤害。
3. **设施维护欠账（`maintenance_debt`）退化与大修公式**：
   - 每 `20` 周期（`200 tick`）在 `P7` 自动从本地 `available` 扣取 `S1–S4` 维护件。若库存不足，未足额缴纳比例累加为欠账期数 $D_{\text{maint}} \ge 0$：
     $$\text{设备可用率 } \alpha_{\text{avail}}(D_{\text{maint}}) = \max\!\big(0.20,\; 1.0 - 0.30\, D_{\text{maint}}\big)$$
   - 当 $D_{\text{maint}} \ge 2.0$ 时，每周期有 $8\% \times D_{\text{maint}}$ 的确定性伪随机概率发生机械故障停机（强制停产 `4` 周期）；补齐历史欠缴维护件的 **`1.20 倍`** 并停机检修 `2` 周期，可将 $D_{\text{maint}}$ 清零并恢复 `100%` 可用率。

### 4. 电网潮流、电化学储能折旧与核电热安全状态机（`Q17`）

1. **连通子电网分带潮流分配（每 tick `P3` 执行）**：
   - 未铺设 `E02` 跨区电网前，各枢纽电站仅向本枢纽内部供电；铺设高压线后，按图连通分量聚合发电出力，跨边传输扣除线损 $\ell_{uv}$ 且受线路热容量上限 $K_{uv}$ 截断。
   - 当供小于求时，按 **Band 1（核电冷却水泵、民生最低医院供水、战略通信雷达）→ Band 2（在途工程验证实验室、受控农场）→ Band 3（按玩家设定优先级的工业产线等比降载）→ Band 4（电解制氢与储能充电）** 严格依序分配。
2. **电化学储能站（`E04`）循环寿命方程**：
   - 储能站占用 `S2` 槽位，一次性装机消耗 `battery × 8`（建设费同 `S2`），额定储电容量 **`80.0` 电·周期**（`800` 电·tick），最大充放电功率 `10.0` 电/周期，**充放往返效率 `85%`**（充入 `1.0` 电存入 `0.85` 可放净电量）。
   - **循环衰减**：每完成 `1` 次满充满放等效循环（累计吞吐 `80.0` 电·周期），电池健康度 `SoH` 衰减 `0.8%`；当 `SoH < 80%` 时需补充更换 `battery × 2` 恢复满容，真实拉动中后期 `copper`、`pure_chemicals` 与 `rare_ore` 持续需求。
3. **核能发电（`P073`）冷却水耦合与热应力停堆规则**：
   - `P073` 每 tick 刚性需求本地 `water × 0.20`（即 `2.0`/周期）。设当 tick 实得冷却水比例为 $r_w \in [0, 1]$：
     - 当 $r_w < 1$ 时，当 tick 发电出力立即按 $r_w$ 线性降载，且堆芯余热累积热应力：`thermal_stress_mU += round((1 - r_w) * 200)`；水源充足（$r_w = 1$）时每 tick 自然消散 `-50 mU`。
     - 若 `thermal_stress_mU >= 1000`，触发 **保护性紧急停堆（SCRAM）**：反应堆强制离线冷却 **`10` 周期**，且必须消耗 `precision_parts × 2 + pure_chemicals × 1` 完成安全检修后方可重启（不做夸张的全图毁灭爆炸，但会造成致命的重工业基荷断电危机）。若运行中的核电站直接遭受高强度轰炸损毁，本枢纽产生持续 `30` 周期的工业停滞与环境去污成本。

## 玩家会因此作出什么不同选择

1. **在“风光+电池+氢能”与“铀矿+核电+高温工艺”间形成鲜明路线分化**：多风光照地区可走 `E03 + E04 + E07` 智能微网；富铀临河国家则可走 `E05 + E08`，用一座核电站同时解决 `20` 单位基荷电力并将同城钢铁水泥厂的煤炭消耗砍半，但必须严密防空护卫水泵与反应堆，防止敌军断水诱发紧急停堆。
2. **科研布局必须兼顾育才（`R02`）与抗打击容灾（`R08`）**：想冲三四阶计算研发（`R07`），必须提前 20–30 周期建技术学院储备工程师；而在大国热战边缘，把关键实验室通过 `R08` 备份到内陆纵深城市，可避免前线名城失守导致数千点四阶科研进度归零。
