# 强对手校准流程

私有参考对手是正式评测的基准，**不公开，也不会提供**。`kaggriculture` 的 champion 是公开对手（RSIdemo 冠军包），但同样由这边代跑。需要校准时，由仓库作者在私有环境代跑。

## 适用范围

有参考对手的 4 道策略题：`ai_training`、`backbone`、`cache_duel`、`kaggriculture`。

## 如何提交

1. 把对手放进 `calibration/<题目>/<名称>.py`，格式与正式提交相同，只能用标准库。
2. 发 Pull Request 或 issue，写明题目、版本和想验证的问题。

## 返回什么

- 分数、分项和置信区间
- 对每个官方对手的胜负统计

不返回官方对手的代码、对局回放和逐步动作。校准结果只用于调试，不算正式成绩。

正式评分对资源要求较高，需要等作者安排在大内存机器上运行，不保证时效。
